# Shopify Gift Card App

A Shopify app for creating customizable PDF gift cards.

The application is intended to simplify the creation of printable gift cards by combining Shopify gift card data with customizable HTML templates, images and QR codes.

## Planned features

- Create Shopify gift cards
- Retrieve the full gift card code during creation
- Select or upload a gift card image
- Configure a QR code target URL
- Generate gift cards from customizable HTML/CSS templates
- Preview the generated gift card
- Export the result as PDF
